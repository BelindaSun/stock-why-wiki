# industry: biotech — 生物科技
_Last updated: 2026-08-30_ · _趋势：分化（主题驱动）_

一句话：研发创新药、疫苗、疗法的高风险高回报行业。与半导体的「估值逻辑」完全不同——**股价由临床数据「二元」跳变**（试验成功可翻倍，失败可腰斩），而非线性的营收/利润。

## 相关标的（从条目里累积）
- [[MRNA]] Moderna — mRNA 平台，癌症疫苗三期成功（来自 2026-08-24 条目）
- [[BNTX]] BioNTech — mRNA + ADC，从新冠转型肿瘤（来自 2026-08-24 条目）
- [[MRK]] 默沙东 — 肿瘤巨无霸，Keytruda + Moderna 疫苗合作（来自 2026-08-24 条目）

- [[VRTX]] 福泰 — CF 隐形冠军 + 非阿片止痛药，创历史新高（来自 2026-08-24 条目）
- [[PFE]] 辉瑞 — 大象转身，专利悬崖 + 转型（来自 2026-08-24 条目）
- [[AMGN]] 安进 — 带 MariTide 挑战减肥药双雄（来自 2026-08-24 条目）

- [[ISRG]] Intuitive Surgical — 手术机器人装机与耗材/服务飞轮；属广义医疗健康，非临床二元型 biotech（来自 2026-08-30 条目）

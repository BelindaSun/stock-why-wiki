# industry: china-tech — 中国科技
_Last updated: 2026-09-23_ · _趋势：国产替代 + 政策支持双轮驱动，与美国 AI 链分叉_

一句话：以 BAT 级平台 + 国产半导体/云/大模型为核心的中国科技资产群。它的驱动逻辑与美国 AI 链**根本不同**：美国出口管制 → 国产替代叙事 + 政策支持 + 内需市场。硬塞进 [[industry:ai-infrastructure]] 或 [[industry:semiconductors]] 会把因果链搅浑，所以单独成档。

## 与主线的衔接
- 与 [[industry:ai-infrastructure]]：同一 AI 资本开支大浪，但供给侧分叉——美国链（[[NVDA]]/[[AVGO]]/[[TSM]]）vs 中国自主链（国产芯片 + 云），出口管制是分叉点
- 与 [[industry:semiconductors]]：中国芯片是半导体板块内的"平行宇宙"，估值与催化与美国链不同步
- 与 [[industry:macro-rates]]：同受分母（美债收益率）影响，但人民币资产另有政策利率与汇率两条线

# industry: glp1-obesity — 减肥药 / GLP-1
_Last updated: 2026-08-24_ · _趋势：爆发式增长，但双雄命运分岔_

一句话：以 GLP-1 类药物（司美格鲁肽、替尔泊肽等）治疗肥胖/糖尿病的超级赛道。市场规模被普遍看作未来十年最大的医药机会之一，但当前是**两家寡头 + 命运分岔**的格局。

## 双雄格局（从条目里累积）
- [[LLY]] 礼来 — **领跑者**。tirzepatide（Mounjaro/Zepbound）减重更强，GLP-1 市占 ~56.7%、美国肥胖市场 >60%，还在扩大（来自 2026-08-24 条目）
- [[NVO]] 诺和诺德 — **开创者、今追赶者**。semaglutide（Ozempic/Wegovy）先火，现市占 ~37.1% 且萎缩，从高点跌 56%（来自 2026-08-24 条目）

## 四条战线（现在在拼什么）
1. **药效**：替尔泊肽减重 > 司美格鲁肽 → 礼来的核心优势
2. **口服药**：下一个战场，把"针剂"变"药片"（礼来 Foundayo/orforglipron vs 诺和口服 Wegovy）
3. **定价战**：MFN 最惠国定价 + Medicaid 缩减 + 诺和自行降价 50% → 全行业单价承压
4. **下一代管线**：诺和 CagriSema 三期失利，翻盘武器哑火

## 关键判断
- **不是行业不行，是竞争分出了输赢**：同一个爆发赛道，礼来上调指引、诺和下调，靠的是药效+执行的差距
- **降价是双刃剑**：市场做大（更多人用得起）但单价利润承压，板块整体有定价逆风
- 与 [[industry:mrna-oncology]] 同属 [[industry:biotech]]，但逻辑不同：这里更看"商业执行 + 市场份额"，不是纯临床二元赌

## 待补

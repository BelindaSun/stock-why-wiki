## 2. ⚠️⚠️ 两条铁律(违反会白屏,且不报错)

这两条是**血的教训**,存盘前必须遵守:

1. **绝不调用未定义的函数**。曾经 `swText()` 被只调用、没定义,直接把两张图画成**白屏**。它现已定义在**引擎开头**——**永远别删它**,也别引入其它"只调用未定义"的函数。

2. **存盘前必须在浏览器里打开,肉眼确认能渲染出节点**。这类错误**不抛语法错误、只白屏**——不肉眼验根本发现不了。改完 → 浏览器打开 → 看到节点和连线正常 → 才算完成。

> 记住:白屏是静默的。你以为存好了,其实全挂了。**每次都验。**

## 3. 节点与边的视觉约定(小德和图窗口一路定下来的)

**节点类型:**
- **实心(金色)** = 已上市公司(有 ticker):NVDA/AAPL/AMZN/AVGO/ORCL...
- **紫色 + 虚线环 + 更大半径 + "未上市"标签** = 关联实体/私有公司:OpenAI、Anthropic(详情卡标"关联实体 · PRIVATE")。用了主题自适应的 `--private-ink`,深浅两色都要清晰。
- **虚线 stub** = 占位待补的节点(还没建完整档)。建完档后"升实心"。
- **行业节点** = 主题/行业(ai-infrastructure、semiconductors、cloud-computing、power-energy、foundation-models、digital-advertising、consumer-tech、autonomy-robotics、space-satellite...)。

**边(连线)类型:**
- **因果边**:上游→下游(如 GEV 电力 → VRT → 服务器 → 芯片)
- **竞争/同类 peer 边**:如 HBM 三强(MU/SKHY/SSNLF)聚成一簇;云三巨头(AMZN/MSFT/GOOGL);AVGO↔NVDA(ASIC vs GPU)
- **包含边**(点线):ETF→成分股,如 SMH→持仓,样式区别于因果边
- **投资⇄算力 双向边**(AI 资本循环):MSFT⇄OPENAI、AMZN⇄ANTHROPIC(标"投资/算力/ROI实证")
- **集中风险粗边**:ORCL→OPENAI(~45% backlog)、CBRS→OPENAI(80%);量级越大越粗

**状态标签**:节点可带状态(如"财报跳涨""指引再上调""IPO 进行中""估值消化")。目前所有股票统一金色,**没做"情绪色"**(强势/回调/承压是稍大改动,用户暂缓——想做要先跟用户确认再另开一轮)。

## 4. 更新流程

1. **收到建档窗口的建图提示**(消息里会写:新增/升实心哪个节点、连什么边、状态怎么标)。
2. 在对应的图 HTML 里改数据(节点数组 + 边数组)。
3. 若是新行业节点,记得加进图例。
4. **浏览器打开验渲染**(见第 2 节铁律)。
5. 重新发布 Artifact,回消息告诉建档窗口"接完、重发了",并简述改了什么。
6. **导览浮层**:图里内嵌了一个"📖 导览"浮层(分层走查 + 一图流 + 几条主线)。wiki 的 overview.md 更新时,同步更新浮层内容,两边保持一致。

---

## 5. 已知的分工边界

- **macro-rates(宏观利率)只留 wiki、不进图**(Belinda 的决定)——收到它的更新**不用动图**。
- **医药图独立**:REGN/ISRG 等医药标的进 `graph-biotech.html`,别和 AI 图混。有窗口可能已经接好了,先看再动、别重复。
- **死链问题**:图是发布在 claude.ai 的 Artifact,跑在浏览器沙箱里,**打不开用户本地的 wiki 文件路径**。所以别在图里做"跳转到本地 .md"的链接(会死链),要引用就把内容内嵌进发布页。

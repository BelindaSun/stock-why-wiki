## 2026-08-24 — 核心看点:AI capex 的 ROI 样板(与 Meta 对照)
**Move:** 非单一价格事件,基本面/ROI 逻辑分析
**Catalyst confidence:** confirmed(财报)

**核心结论:** Amazon 是"巨额 AI capex 到底有没有回报"这题的最强正面证据——**在 capex 猛增的同时,AWS 利润率还大幅扩张**,说明自研芯片战略真在赚钱。

**关键数据(2026):**
- AWS Q2 营收 $422 亿,**+37%(18 个季度最快)**,年化 run rate $1690 亿
- **AWS 运营利润率 39.4%(同比 +650bp)——capex 猛增的同时利润率还涨**,是 ROI 最硬的证据
- 全年 capex 上调至约 **$2200 亿**(单季资本开支 $542 亿,同比翻倍)
- Trainium2 性价比比同类 GPU 好约 30%,几乎售罄;Trainium3 已开始出货;合约需求 >$2250 亿
- Bedrock 12.5 万客户(80% 财富 100 强);AI 服务与芯片业务各自年化 run rate 破 $250 亿,三位数增长
- Anthropic 持股非现金增值 $534 亿,主导了当季净利

**因果链(为什么 ROI 硬):**
1. 自研 Trainium 降本 30% → 同样算力更便宜 → 客户愿买、利润率能扩
2. Anthropic/OpenAI 锁定多吉瓦 Trainium 长约 → 需求可见度极高
3. Bedrock 分发到 80% 财富 100 强 → AI 变现有现成企业客户渠道
4. capex↑ 但利润率↑ → 证明这不是"烧钱换叙事",是"投入换真实回报"

**对照 [[META]]:** 同样砸千亿,Amazon 的 FCF/利润率证据链清晰(有云客户直接付费),Meta 的第三块(新 AI 产品)仍是押注。这就是市场对两者态度的分野。

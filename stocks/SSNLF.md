# SSNLF — Samsung Electronics
_Asset type: stock (KRX 005930 / OTC SSNLF)_ · _Last updated: 2026-08-24_

存储三强之一(HBM 市占约 28%,居 [[SKHY]] 之后、[[MU]] 之前),同时是全球最大综合电子/代工厂之一。HBM 是其重新追赶 AI 红利的关键战场。

## Upstream — what drives it
- [[ASML]] — 存储与代工先进制程的光刻设备
- 先进封装/3D 堆叠技术 — HBM 竞争力核心(FMS 2026 上展示 3D 内存、zHBM/HBM5)
- 半导体设备/材料 — 自有晶圆厂庞大资本开支

## Downstream — what it affects
- [[NVDA]] [[AMD]] [[CBRS]] — HBM4 供应商之一,追赶 SK Hynix 的份额
- [[MU]] [[SKHY]] — HBM 直接竞争对手,三家瓜分市场
- 消费电子/晶圆代工 — 手机/面板/Foundry 等庞大非 AI 业务盘

## Timeline (newest first)

## 2026-08-24 — HBM 追赶提速:HBM4 环比增超 3 倍,量产行业首发
**Move:** 补档记录(相对 [[SKHY]]/[[MU]] 的存储三强定位);受 Temasek 注资等消息带动情绪
**Catalyst confidence:** confirmed(公司数据/产品)

**What happened:**
三星是 HBM 三强里的"追赶者":早期 HBM3E 有良率问题,现正aggressive 爬坡。它已量产行业首款商用 HBM4,预计 Q3 HBM4 销售环比增超 3 倍、占 HBM 收入结构 60%+。在 FMS 2026 展示 zHBM/zNAND、400+ 层 V10 NAND、HBM4E/HBM5 概念,技术路线激进。为腾出本土 HBM 产能,考虑把通用 DRAM/NAND 封测移至越南。与 SK Hynix 一同获新加坡主权基金 Temasek 注资传闻带动股价。

**Causal chain:**
1. AI HBM 需求爆发 + 三星此前掉队 → 存在"追赶补涨"空间
2. HBM4 行业首发量产 + Q3 环比增 3 倍 → 份额与营收结构快速改善
3. 腾挪通用存储产能给 HBM + 主权基金注资 → 供给与资金双重加码
4. 但仍落后 SK Hynix(28% vs 54%)→ 弹性大、但执行/良率仍是变量

**注:** 三星补齐了 HBM 三强的最后一角。至此图里存储侧 = [[MU]] + [[SKHY]] + [[SSNLF]],共同供 [[NVDA]]/[[AMD]]/[[CBRS]]。

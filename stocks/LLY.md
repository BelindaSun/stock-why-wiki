# LLY — Eli Lilly
_Asset type: stock (NYSE)_ · _Last updated: 2026-08-24_

减肥药(GLP-1)战争的**领跑者**。核心药物 tirzepatide——糖尿病版叫 Mounjaro、减肥版叫 Zepbound，减重效果强于对手的 semaglutide。GLP-1 市占约 **56.7%**、美国减肥药市场 **>60%**，且仍在扩大领先。是 [[NVO]] 诺和诺德的头号对手。

## Upstream — what drives it
- **tirzepatide franchise**（Mounjaro + Zepbound）— 营收发动机，减重数据领先是护城河
- 口服 GLP-1 管线（Foundayo / orforglipron）— 下一个战场：把针剂变药片
- 产能 / 供应链 — GLP-1 长期供不应求，扩产能力直接决定能卖多少
- 临床试验 / 适应症扩展 — 心血管、睡眠呼吸暂停等新适应症持续扩大市场

## Downstream — what it affects
- [[NVO]] 诺和诺德 — 头号对手，此消彼长：礼来抢的份额多来自诺和
- 肥胖相关疾病版图 — 减肥药正侵蚀心血管、糖尿病等多个大市场
- GLP-1 代工 / 供应链 — 针剂、笔、原料药的庞大外包需求
- 消费 / 医疗支出 — 减肥药普及正外溢影响食品、健身等行业

## Related industries / themes
- [[industry:glp1-obesity]] — 减肥药双雄之一，且是**赢家**：靠药效 + 执行力持续扩大领先
- [[industry:biotech]] — 大盘制药，但增速极快（2026 指引营收 $850–870 亿、+25%）

## 2026-08-24 — 持续走强：Q2 超预期、上调指引，领先越拉越大
**Move:** Q2 营收利润双超预期，上调全年营收指引至 $850–870 亿（原 $820–850 亿），指引增速约 +25%  ·  **Catalyst confidence:** confirmed（财报）
**What happened:** 礼来在减肥药战争里**赢面越来越大**。tirzepatide 减重效果强过诺和的 semaglutide，美国肥胖市场份额已 >60%，销量口径持续超越对手。2026 营收指引一路上调。与 [[NVO]] 形成鲜明反差——同一个火爆赛道，一个上调、一个下调。
**Causal chain:**
1. tirzepatide 减重数据领先 → 医生/患者更认，份额向礼来集中
2. 需求爆棚 + 礼来扩产跟上 → 销量口径持续超诺和
3. 口服药 Foundayo 卡位下一战场 → 打开"针剂→药片"的更大市场
4. Q2 超预期 + 上调指引 → 领先地位被财报反复确认
**和 [[NVO]] 的对比:** 礼来是"药效 + 执行"的赢家；诺和则被下一代药 CagriSema 三期失利 + 降价压力拖累。**同一赛道，命运分岔。**

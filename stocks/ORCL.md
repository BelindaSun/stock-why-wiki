# ORCL — Oracle
_Asset type: stock (NYSE)_ · _Last updated: 2026-09-12_

传统数据库巨头,靠 **OCI(Oracle 云基础设施)**在 AI 时代逆袭成"第四朵云"。2026 年因承接 [[OPENAI]] 等天量 AI 算力订单,RPO(积压合约)爆炸式增长。是"AI 资本循环"里被 OpenAI 需求直接点燃的关键一环。

## Upstream — what drives it
- [[NVDA]] — OCI 数据中心的 GPU 主力
- [[AVGO]] / 自研 — 网络与定制芯片
- 数据中心/电力 — 疯狂扩产,拉动 [[VRT]] [[GEV]]、举债融资
- [[OPENAI]] — 最大单一客户,占 backlog 约一半(既是引擎也是集中风险)

## Downstream — what it affects
- [[OPENAI]] — 为其提供大规模训练/推理算力(OpenAI $1.15万亿基建承诺里 Oracle 占 $3000亿)
- 企业云/数据库客户 — 传统基本盘
- [[AMZN]] [[MSFT]] [[GOOGL]] — 云竞争,Oracle 以"AI 中立第三方"抢份额
- AI 训练/推理市场 — 算力供给的重要增量

## Related industries / themes
- [[industry:cloud-computing]] — 从"落后者"变 AI 云黑马,RPO 增速冠绝同行
- [[industry:ai-infrastructure]] — 需求侧算力供给方;但重资本 + 客户集中是双刃

## Timeline (newest first)

## 2026-09-10 — FQ1 财报炸裂:RPO 飙到 $6640 亿,但一半绑 OpenAI
**Move:** 9/9 盘后财报,RPO 数字引爆关注(此前已成"押注 OpenAI 最干净的方式")
**Catalyst confidence:** confirmed(财报)

**What happened:** Oracle FQ1(FY27)大超预期:营收 $193.5 亿(超 $191.4 亿预期),非 GAAP EPS $1.92(超 $1.74);OCI 收入同比 **+121% 到 $74 亿**。但真正炸场的是 **RPO 积压合约飙到 $6640 亿**(单季新签 $300 亿+ AI 云合约,同比大增)。这把 Oracle 变成了"AI 算力需求"最直接的上市代理之一。

**Causal chain:**
1. AI 训练/推理需要海量算力 → 云厂商疯抢 → Oracle 以"中立第三方"承接大单
2. 签下天量多年合约 → RPO 爆炸到 $6640 亿,给出远期收入可见度
3. 市场把 Oracle 当成"买 OpenAI 的干净渠道"(约一半 backlog 绑 OpenAI)→ 估值随 AI 叙事重估
4. 但为交付要疯狂举债扩数据中心 → 现金流/杠杆承压

**核心张力(为什么"炸裂"里藏隐忧):**
- **客户集中**:约一半 backlog 系于 [[OPENAI]] 一家 → OpenAI 若放缓/自建/转单,Oracle 首当其冲(和 [[CBRS]] 80% 绑 OpenAI 同类风险,只是量级更大)
- **重资本吞现金**:RPO 是"承诺"不是"现金",兑现要先砸巨额 capex 举债
- **循环依赖**:它是"AI 资本循环"的一环——OpenAI 靠融资付它、它举债建算力给 OpenAI,一荣俱荣一损俱损

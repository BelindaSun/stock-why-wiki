## Timeline (newest first)

## 2026-08-24 — 核心问题:capex 跑赢回报?OpenAI 绑定是福是祸?
**Move:** 股价一度接近一年低位,capex 指引重定价了市场预期
**Catalyst confidence:** confirmed(财报)

**核心结论:** MSFT 卡在 [[AMZN]](ROI 已证明)和 [[META]](ROI 存疑)之间——它有实打实的 AI 收入($370 亿 run rate),但 capex 增速太猛、利润率被压,市场担心"需求→持久 FCF"的转化跟不上。OpenAI 是它的独特护城河,也是独特集中风险。

**关键数据(2026):**
- Azure Q4 FY26 +43%,年营收破 **$1000 亿**;AI 收入 run rate **$370 亿(+123%)**
- 2026 capex 指引约 **$1900 亿(+61%)**,超市场共识约 $350 亿(其中 ~$250 亿是组件涨价)
- M365 Copilot 3000 万付费席位(环比净增翻倍);GitHub Copilot 5000 万用户
- 商业 RPO $6780 亿(+84%),但**约 45% 绑定 OpenAI**
- 云毛利率指引降至约 64%(多季度压缩);持 OpenAI 27%,当季确认 $76 亿收益
- 新协议:取消 Azure 独家性、取消 IP 分成、AGI 终止条款移除,OpenAI 20% 分成延到 2030 但设上限

**因果链(为什么有收入还被质疑):**
1. Azure/Copilot 有真实付费需求 → AI 收入高速增长(不缺需求)
2. 但 capex +61% 太猛 + 组件涨价 → 云毛利率多季度压缩
3. 数据中心/芯片是"现在花钱",AI 收入是"未来多年才到" → 市场担心转化率
4. 与同行比,激进 capex 没换来更优的营收/利润率趋势 → 效率被质疑
5. OpenAI 占 45% RPO → 深绑既是模型护城河,又是集中风险(新协议还削弱了独家性)

**本质:** 争议不在"有没有需求",而在"需求变成持久自由现金流的速度"。MSFT 的 AI 收入比 Meta 实,但 capex 效率证据不如 Amazon 硬,加上 OpenAI 绑定的双刃剑——所以估值处在"信但要看兑现"的观望期。

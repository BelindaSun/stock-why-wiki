# REGN — Regeneron Pharmaceuticals
_Asset type: stock (NASDAQ)_ · _Last updated: 2026-08-30_

平台型生物制药公司：用抗体发现引擎不断产出产品，再由 Dupixent 分成、EYLEA HD 和 Libtayo 的现金流继续供养研发。与单一临床事件型 biotech 不同，REGN 的核心是**多产品研发复利**。

## Upstream — what drives it
- **Dupixent（与 Sanofi 合作）** — 跨皮肤、呼吸、胃肠和过敏等适应症的最大增长引擎
- **EYLEA HD / EYLEA** — 眼科现金流；升级换代与生物类似药竞争同时发生
- **抗体与人类遗传学研发平台** — 新适应症和新分子的长期来源
- 监管、支付与制造 — 决定生物药的可及性和商业规模

## Downstream — what it affects
- [[industry:biotech]] — 平台型生科“研发 → 产品 → 现金流 → 再研发”的代表
- Sanofi — Dupixent 合作方，双方共同分享增长
- 眼科药物市场 — EYLEA HD 的转换影响同类抗 VEGF 产品与生物类似药
- 免疫、肿瘤与罕见病同业 — 关键试验会改变各细分赛道竞争

## Related industries / themes
- [[industry:biotech]] — 多产品、现金流为正的平台型生科
- 免疫 / 眼科 / 肿瘤 — 三条不同风险来源的业务主线

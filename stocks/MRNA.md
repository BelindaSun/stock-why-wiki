# MRNA — Moderna
_Asset type: stock (NASDAQ)_ · _Last updated: 2026-08-24_

mRNA 技术平台公司。曾靠新冠疫苗一战成名，如今把同一套 mRNA 技术转向**癌症疫苗**等新方向。与默沙东（[[MRK]]）在个性化癌症疫苗上深度合作。是「mRNA 疗法」这一新兴主题的龙头。

## Upstream — what drives it
- [[MRK]] 默沙东 — 癌症疫苗合作方，其 Keytruda 与 Moderna 疫苗联用；临床/商业化靠它
- mRNA / LNP 技术平台 — 公司核心资产，一套平台可延伸到多种疾病
- FDA / 临床试验结果 — 生物药的股价由试验数据「二元」驱动（成/败一线之间）
- 研发现金消耗 — 持续烧钱，融资环境与账上现金决定能撑多久

## Downstream — what it affects
- [[MRK]] 默沙东 — 合作共享收益，疫苗成功对它也是利好
- 其他 mRNA / 癌症疫苗公司（如 BioNTech [[BNTX]]）— 板块情绪同涨，验证 mRNA 抗癌路线
- CRO / 疫苗代工 — 若疫苗放量，生产与临床外包需求上升
- 新冠疫苗同业 — 提示 mRNA 平台「后新冠」的第二增长曲线

## Related industries / themes
- [[industry:mrna-oncology]] — 加速：mRNA 从「传染病疫苗」扩展到「癌症治疗」，打开长期想象空间
- [[industry:biotech]] — 高风险高回报，股价由临床数据「二元」跳变，与半导体的估值逻辑完全不同

## 2026-08-24 — 单日暴涨 +177%：癌症疫苗三期成功
**Move:** 8/19 单日 +176.97%（$62.96 → $174.38），成交量约平时 28 倍  ·  **Catalyst confidence:** confirmed（临床数据）
**What happened:** Moderna 与默沙东公布个性化 mRNA 癌症疫苗（intismeran autogene，原 mRNA-4157）联合 Keytruda 治疗黑色素瘤的**三期临床达到主要终点**（无复发生存 + 无远端转移生存）。市场对 mRNA 抗癌前景极度兴奋，Guggenheim 估计仅黑色素瘤辅助治疗一项就有 $20 亿+ 潜在年收入。
**反面（为什么不能无脑追）:** 公司 Q2 仍净亏 $7.82 亿、持续烧现金、预计到 FY2028 每股收益仍为负；疫苗真正贡献收入要好几年后。这是一次「预期驱动」的暴涨，不是当前业绩。
**Causal chain:**
1. 癌症疫苗三期临床成功 → 2. mRNA 平台被验证可用于抗癌（不只是新冠）→ 3. 打开数十亿美元级长期市场想象 → 4. 资金蜂拥买「预期」，单日 28 倍量暴涨 +177%
